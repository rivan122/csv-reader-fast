A faster drop-in for csv-reader 1.0.0: the same reading of broken CSV and the same answers, with fields sliced out of the text instead of built one character at a time, and quoted fields found with `indexOf`. Dependency-free, Node 22, no network, deterministic.

## Run it

```sh
MAKEFUN_INPUT_DIR=<dir with cases.json> MAKEFUN_OUTPUT_DIR=<out dir> node main.ts
```

`main.ts` reads every case from `/input/cases.json`, answers each with `run` from `solve.js`, and writes `/output/answers.json`.
